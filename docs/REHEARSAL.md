- [ ] 본행사 행사 생성, 참가 코드 생성(`node tools/codes.mjs …`) → `private/` 의 CSV 로 개인별 쪽지·스티커 인쇄
- [ ] 이름 확인: 참가 코드 CSV 의 이름(학생001 …) ↔ 실제 학생 명단 대응표는 **학교 안에서만** 보관

## 리허설 당일 (같은 강당, 같은 시간대 권장)
- [ ] 무대 PC: 전광판 링크로 열기 → **전체화면** → 프로젝터 해상도(16:9)에서 글자·QR 크기 확인
- [ ] 무대 PC 는 유선 인터넷 또는 안정적인 와이파이. 절전·화면보호기·자동 업데이트 끄기
- [ ] 객석 맨 뒤·양 끝에서 QR 코드가 찍히는지, 주소가 읽히는지
- [ ] 통신사별 휴대폰(SKT·KT·LGU+, 알뜰폰)으로 입장 → 답 제출 → "접수 완료" 표시까지 걸리는 시간
- [ ] 카카오톡 인앱 브라우저·삼성 인터넷·사파리·크롬에서 입장·제출 확인
- [ ] 한글 입력: 조합 중 Enter 가 제출되지 않는지, 제출 버튼이 크게 잘 눌리는지
- [ ] 비행기 모드 켰다 끄기 → "다시 연결 중" 후 같은 참가자·같은 답으로 복귀하는지
- [ ] 같은 코드로 두 번째 기기 입장 → 첫 기기에 "다른 기기에서 입장" 안내가 뜨는지
- [ ] 진행자 PC 와 전광판 PC 를 분리할지 결정. 진행자 화면 새로고침해도 상태가 그대로인지
- [ ] 진행 순서 연습: 첫 문제 준비 → 시작 → (연장) → 마감 → 대표 답안 고르기 → ③ → ④ → ⑤(명단 넘기기) → 다음 문제
- [ ] 정답자 명단이 여러 페이지일 때 넘기는 속도
- [ ] 결과 CSV 내려받기, 엑셀에서 한글이 깨지지 않는지
- [ ] 리허설 후 **시험 행사 초기화**(행사 코드 입력 확인) 또는 본행사용 새 행사 생성
