### 본행사 추정 (500명, 20문항, 1시간)
- 입장·재접속 여유 포함 참가자당 약 10회 + 문항당 평균 2회 제출 → 500 × (10 + 40) ≈ **2.5만 Worker 요청 · 2.5만 DO 요청**
- ping: 500명 × 144회/시간 = 7.2만 메시지 ≈ **3,600 DO 요청**
- Duration: DO 1개가 1시간 내내 메모리에 있다고 가정해도 128MB × 3,600초 ≈ **450 GB-s** (포함량 40만 GB-s)
- SQLite 쓰기: 답안 2만 회 × (행 + 인덱스) + 채점 1만 행 ≈ **5만 행** (포함량 5,000만)
- Worker CPU: 요청당 수 ms(HMAC·JSON) × 2.5만 ≈ **10만 ms 이하** (포함량 3,000만 ms)

→ 단독으로는 포함량의 1% 미만. 단, 계정의 다른 서비스 사용량과 합쳐지므로 대시보드에서 확인할 것.

### 클라우드 부하 시험 1회 추정
로컬 측정의 실제 요청 수(`loadtest/results/*.json` 의 `requests`) 기준:

| 시험 | HTTP 요청 | WebSocket 연결 | 예상 DO 요청 |
|---|---|---|---|
| 500명 · 3문항 · 혼합 | 약 2,400 | 약 670 | 약 3,100 |
| 1,000명 · 3문항 · 혼합 | 약 4,800 | 약 1,330 | 약 6,200 |

+ 코드 생성(참가자 1명당 DO 내부 쓰기 1행), 결과 내보내기. 5~10회 반복해도 수만 요청 수준.
부하 시험 도구는 `--max-requests`(기본 20,000)·`--max-seconds`(기본 900) 상한에서 멈추고 Ctrl+C 로 즉시 중단할 수 있다.

## 사용량 확인 방법
1. Cloudflare 대시보드 → **Workers & Pages** → `nobrain-festival-quiz-test` → **Metrics**: 요청 수·오류·CPU 시간
2. 같은 Worker → **Durable Objects** 탭(또는 Storage & Databases → Durable Objects): 요청 수·Duration·저장 용량·행 읽기/쓰기
3. 계정 → **Billing** → 청구 가능 사용량(Billable usage): 계정 전체 합계
4. 실시간 로그: `npx wrangler tail --env test` (코드·쿠키는 로그에 남기지 않음)
