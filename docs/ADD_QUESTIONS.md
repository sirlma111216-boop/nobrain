# 문제세트와 문제 추가

행사를 만들 때 **문제세트**를 고릅니다(진행자 화면 → 새 행사 만들기 → 세트 선택). 고른 세트는 그 행사에 고정됩니다.

| 세트 ID | 제목 | 문항 | 위치 |
|---|---|---|---|
| `basic` | 시험 문제 3개 | 3 | `worker/quiz/bank.ts` |
| `set1` | 문제세트 1 (리허설 20문항) | 20 | `worker/quiz/sets/set1.ts` (그림 `public/media/s1/`, 생성기 `tools/make-set1.mjs`) |
| (가져온 세트) | CSV 로 만든 세트 | — | `worker/quiz/sets/<id>.ts`, 그림 `public/media/<id>/` |

모든 문제 데이터는 **서버(Worker) 전용**입니다. 학생·전광판 번들에는 정답이 들어가지 않습니다(`npm run test:unit` 의 유출 검사가 모든 세트를 확인).

## 문제세트 1
리허설용 20문항입니다: 개수 세기, 시계 읽기, 도형·색 이름, 사과 덧셈, 수 배열, 신호등, 무지개, 주사위, 크기 비교, 화살표 방향, 달.
그림은 모두 직접 그린 SVG 이며 외부 사이트의 그림·문제는 쓰지 않았습니다. 문제를 고치려면 `tools/make-set1.mjs` 를 고친 뒤 실행하세요.
```bash
node tools/make-set1.mjs
```

## 실제 축제 사진으로 세트 만들기 (가져오기 도구)

1. 폴더를 하나 만들고(예: `quiz-sets/festival/`) 그림 파일과 `questions.csv` 를 넣습니다. `quiz-sets/` 는 git 에서 제외되어 원본이 공개 저장소에 올라가지 않습니다.
2. `questions.csv` 는 [questions-template.csv](questions-template.csv) 를 복사해 엑셀에서 채우고 **CSV UTF-8** 로 저장합니다.

| 열 | 필수 | 설명 |
|---|---|---|
| 번호 | | 참고용(순서는 줄 순서) |
| 질문 | ○ | 전광판에 나오는 질문 |
| 그림 | ○ | 같은 폴더의 파일 이름 (png·jpg·webp·svg·gif) |
| 대표정답 | ○ | 전광판에 공개할 정답 |
| 인정답안 | | `\|` 로 구분. 대표정답은 자동 포함 |
| 해설 | | 정답 공개 때 보이는 짧은 설명 |
| 제한시간 | | 초, 기본 20 |
| 띄어쓰기무시 / 대소문자무시 | | Y/N, 기본 Y |
| 오답예시 | | `\|` 로 구분. 연습용 봇이 낼 흔한 오답(채점에는 안 씀) |

3. 가져오기:
```bash
node tools/import-set.mjs --dir quiz-sets/festival --id festival --title "축제 본행사"
```
   - 그림은 `public/media/festival/` 에 **무작위 해시 이름**으로 복사됩니다(파일 이름으로 정답이 새지 않음).
   - 빈 칸·없는 그림·잘못된 제한시간이 있으면 아무것도 만들지 않고 문제 줄을 알려 줍니다. 1.5MB 넘는 그림은 경고합니다.
   - 같은 ID 로 다시 실행하면 덮어씁니다. 지우기: `node tools/import-set.mjs --remove festival`
4. 확인 후 배포:
```bash
npm run test:unit
```
```bash
npm run deploy:test
```

## 채점 규칙
서버가 NFKC 정규화(전각→반각, 조합형 한글→완성형), 공백 정리, 제로폭 문자 제거 후, 문제별 `띄어쓰기무시`·`대소문자무시`를 적용해
인정답안과 **정확히 일치**하는지만 봅니다. 유사도·AI 판정은 없습니다. 행사 중 놓친 표기는 진행자 화면의 "정답 인정"으로 추가·재채점하세요.

## 그림·저작권 주의
- 파일 이름, SVG 안의 주석·`aria-label`·`<title>` 에 정답을 쓰지 마세요. 정적 파일은 누구나 받을 수 있습니다.
- 다른 사이트의 그림·문제를 그대로 가져오지 마세요. 직접 찍거나 만든 사진, 또는 사용 허락을 받은 그림만 쓰세요.
- 사람 얼굴 사진은 당사자(학생은 보호자 포함) 동의를 받은 것만 쓰세요.

## 공개 저장소 주의
현재 GitHub 저장소는 **공개(Public)** 입니다. 세트 파일(`worker/quiz/sets/*.ts`)과 `public/media/` 를 커밋하면 정답과 그림이 GitHub 에서 보입니다.
본행사 세트를 만들기 전에 저장소를 비공개(Private)로 바꾸거나, 본행사 세트는 커밋하지 말고 그 컴퓨터에서 바로 배포하세요.
