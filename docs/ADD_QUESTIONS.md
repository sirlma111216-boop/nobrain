# 문제세트 만들기

문제는 **진행자 화면에서 직접** 만듭니다. 다시 배포할 필요가 없습니다.

1. 진행자 화면 → **📚 문제세트 보기 · 혼자 풀기** (주소 `/host/sets`, 진행자 로그인 필요)
2. **새 세트 이름**을 넣고 **＋ 새 세트 만들기**
3. **문제 추가**
   - **사진**: 칸에 끌어다 놓기 / 눌러서 고르기 / 복사한 사진을 Ctrl+V. 휴대폰 사진(수 MB)도 브라우저가 긴 변 1600px WebP 로 줄여서 올립니다(1.8MB 이하). GIF 는 움직임을 지키려고 그대로 올립니다.
   - **정답**: 전광판에 공개되는 대표 정답 (필수, 30자 이내)
   - **함께 인정할 답**: 한 줄에 하나 (예: `엄마 손 파이`, `엄마손`)
   - **띄어쓰기 무시 / 영문 대소문자 무시**: 기본 켜짐
   - **제한시간**: 기본 20초 (5~300)
   - 선택 항목: 질문 글(비워 두면 **사진만** 나옵니다), 해설, 연습용 봇이 낼 오답 예시
4. 문제 카드에서 **↑ ↓**로 순서, **수정**, **삭제**
5. **혼자 풀기**로 직접 풀어 보며 확인(타이머·순서 섞기·문항 수 선택, 실제 행사와 같은 서버 채점)
6. 진행자 화면에서 **새 행사 만들기 → 세트 선택**

## 알아 둘 것
- 행사를 만들 때 **그 순간의 세트 내용이 행사에 복사**됩니다. 세트를 고쳐도 이미 만든 행사는 바뀌지 않으니, 고친 뒤에는 새 행사를 만드세요.
- 세트를 지워도 사진은 지우지 않습니다(이미 만든 행사가 쓰고 있을 수 있음).
- 채점: 유니코드 정규화(전각→반각, 조합형 한글→완성형)·공백 정리 후, 문제별 띄어쓰기·대소문자 규칙으로 **인정 답과 정확히 같을 때만** 정답. 유사도·AI 판정 없음. 놓친 표기는 행사 중 진행자 화면의 "정답 인정"으로 추가·재채점.
- 정답·해설은 진행자 쿠키가 있어야 받는 API 로만 나갑니다. 학생 화면 번들에는 들어가지 않습니다.
- 사진 주소(`/api/media/<해시>`)는 전광판이 쓰도록 로그인 없이 열립니다. 주소는 추측하기 어려운 해시지만, 공개 전에 정답이 드러나는 사진(정답 글자가 찍힌 사진 등)은 피하세요.
- "시험 문제 3개(기본 예시)"는 코드에 들어 있는 예시 세트로, 수정할 수 없습니다.

## 저작권·초상권
- 직접 찍거나 만든 사진, 또는 사용 허락을 받은 사진만 쓰세요. 다른 사이트의 퀴즈 사진을 그대로 가져오지 마세요.
- 학생·교사 얼굴이 나오는 사진은 당사자(학생은 보호자 포함) 동의를 받은 것만 쓰세요.

## 저장 위치(기술)
세트·문제·사진은 `LibraryDO`(Durable Object 하나, SQLite)에 저장됩니다. 사진은 BLOB(행당 2MB 제한 → 1.9MB 이하)으로 저장하고, 같은 사진은 내용 해시로 한 번만 저장합니다.
